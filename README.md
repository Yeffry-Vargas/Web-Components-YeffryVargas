# Veterinaria San Pío – Fichas de mascotas

## Integrante
- Yeffry Alexander Vargas Reyes

## Caso elegido
Ficha de mascota para una veterinaria.

## Descripción del proyecto

Este proyecto consiste en crear un componente reutilizable utilizando Web Components. Su objetivo es mostrar la información de los pacientes de la Veterinaria San Pío, incluyendo el nombre de la mascota, especie, edad, próxima vacuna y observaciones.

Se utiliza HTML Templates, Custom Elements y Shadow DOM para construir las fichas.
